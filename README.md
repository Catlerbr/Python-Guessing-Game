# Guessing Game

Um mini jogo de adivinhação desenvolvido em Python para praticar conceitos fundamentais de programação.

## Sobre o projeto

O computador escolhe aleatoriamente um número entre 1 e 100, e o jogador precisa descobrir qual é esse número antes que suas vidas acabem.

### Funcionalidades

- Geração de números aleatórios.
- Sistema de 5 vidas.
- Dicas indicando se o número escolhido é maior ou menor que o número secreto.
- Mensagens de vitória e derrota.

## Tecnologias utilizadas

- Python 3
- Biblioteca `random`

## Como executar

1. Tenha o Python 3 instalado.
2. Faça o download do projeto.
3. Execute o arquivo Python pelo terminal.

## Objetivo

Projeto desenvolvido para praticar:
- Estruturas condicionais (`if`, `elif`, `else`).
- Laços de repetição (`while`).
- Variáveis e operadores.
- Entrada e saída de dados.
- Utilização de bibliotecas nativas do Python.
